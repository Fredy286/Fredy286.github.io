Curioseando

Canal de videos cortos en español para YouTube, TikTok, Instagram y Facebook: frases, motivación, reflexiones, humor de chats cotidianos, escenas para canciones y clips de cine clásico de dominio público.

Cómo hacemos los videos

Cada video es una producción propia: textos originales, música original generada con licencia comercial y video de archivo con licencia de uso comercial (Pexels) o películas en dominio público. Cuando un video se hace con ayuda de inteligencia artificial, lo indicamos al publicarlo.

Estudio de Shorts

Para publicar usamos «Estudio de Shorts», una herramienta propia que funciona solo en nuestro equipo. Se conecta únicamente a nuestras propias cuentas mediante las API oficiales de cada plataforma (YouTube Data API, Meta Graph API y TikTok Content Posting API) para subir nuestros videos con su título, descripción y hora de publicación. No ofrece servicios a otras personas ni accede a cuentas de terceros.
